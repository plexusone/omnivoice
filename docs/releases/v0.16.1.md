# Release Notes: v0.16.1

**Release Date:** 2026-11-21

## Summary

A patch release for `omnivoice verify quotes`, through omnivoice-core
v0.20.1. Engines write the same speech in different ways: one hears
"going to" and another "gonna", one hears "workflow" and another "work
flow", and some write a word the speaker broke off. These no longer count
as disputes. It also fixes `omnivoice --version`, which printed 0.10.0.

## Fixed

- **Informal forms**: "gonna", "wanna", "gotta", "kinda", "sorta" and "ok"
  match "going to", "want to", "got to", "kind of", "sort of" and "okay"
- **Split and joined words**: two heard words are joined when together they
  spell one word of the quotation, and one heard word is split when it
  spells two, unless the result is ambiguous
- **Words cut off mid-word**, such as "ha-", are dropped unless they are
  part of the quotation
- **Quotations with elided text** ("…") are located in the shortest
  matching stretch, so a clip no longer runs for minutes
- **`omnivoice --version`** reports the current release

## Dependencies

- Requires `github.com/plexusone/omnivoice-core` v0.20.1
- `github.com/deepgram/deepgram-go-sdk/v3` v3.12.0
- Indirect dependencies updated

## Installation

```bash
go get github.com/plexusone/omnivoice@v0.16.1

```
